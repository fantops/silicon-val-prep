| 4 | Request later start date (8 weeks) | 1 day | Bundled in Tue email |
| 5 | Second counter (after their revised offer) | 1–2 days | Fri 23 May if needed |

**Implication:** Layer A alone won't bridge to AMD/QC closure (3–4 wks out). Plan on **Layer B (accept-then-keep-options) as the committed path** (decided 18 May), not a fallback.

### Layer B — Accept Intel + keep options open (COMMITTED PATH as of 18 May)
**Accept Intel.** Do NOT resign from MSFT yet. Keep AMD / QC / Amazon / Cerebras active.

Reality check on accept-then-renege:
- **Legally safe** in India — acceptance + signed offer is not enforceable employment; you can withdraw before joining.
- **Reputationally costly at Intel BLR team only.** You worked there before; recruiter + HM will remember. Burn factor: medium (not catastrophic, but real).
- **No impact on other employers** — they don't know.
- **Bridge accepted as burned for 3–5 yrs with this specific team** — explicitly OK because you're not planning to return to Intel BLR in that window anyway.

Rules if you go accept-then-renege route:
- **Don't resign from MSFT** until you've decided which offer to actually take.
- **Don't take joining bonus pre-payment** (some companies pre-pay portion — creates refund/legal complexity).
- **Don't start onboarding paperwork** (laptop, IT provisioning) before final commit.
- **Push start date to 8 weeks** (max stall window; recruiter has flex here).
- **Be honest in the renege call** — "competing offer at significantly higher level/TC, hard decision." Don't ghost.
- **Renege via phone call + email follow-up**, not email-only.
- **Renege ≥ 2 weeks before start date** so they can re-engage backup candidates.

### Layer C — When 2+ offers in hand (or Intel deadline is final)

  AMD ≥ ₹70L + L7              →  AMD (renege Intel if accepted)
