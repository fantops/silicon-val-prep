## 7. Decision logic (Intel-timing-realistic)

Intel rarely waits 2 weeks. Plan in 3 layers:

### Layer A — Stall (Intel moves fast, ~1 day per action)
Realistic per-action buffer is **1–2 days max**. Stack them serially. Total realistic buy: **4–7 days**, not weeks.

| # | Tactic | Buys |
|---|---|---|
| 1 | "Need formal letter to review with family." | 1 day |
| 2 | Counter-negotiate TC (sign-on / base / RSU) — 1 round | 1–2 days |
| 3 | Request manager intro call / team scope | 1 day |
| 4 | Request later start date | 1 day |
| 5 | Second counter (after their revised offer) | 1–2 days |

**Implication:** Layer A alone won't bridge to AMD/QC closure (3–4 wks out). Plan on **Layer B (accept-then-keep-options)** as the realistic path, not a fallback.

### Layer B — If Intel forces acceptance before others close
**Accept Intel.** Do NOT resign from MSFT yet. Keep AMD / QC / Amazon / Cerebras active.

Reality check on accept-then-renege:
- **Legally safe** in India — acceptance + signed offer is not enforceable employment; you can withdraw before joining.
- **Reputationally costly at Intel only.** You worked there before; recruiter + HM will remember. Burn factor: medium (not catastrophic, but real).
- **No impact on other employers** — they don't know.

Rules if you go accept-then-renege route:
- **Don't resign from MSFT** until you've decided which offer to actually take.
- **Push start date as far out as Intel allows** (more runway = more loops close).
- **Be honest in the renege call** — "competing offer at significantly higher level/TC, hard decision." Don't ghost.
- **Accept the Intel bridge is burned** for ~3–5 years.

### Layer C — When 2+ offers in hand (or Intel deadline is final)
```
  AMD ≥ ₹70L + L7              →  AMD (renege Intel if accepted)
  QC Staff + team scope OK     →  QC CPU Core (renege Intel if accepted)
  QC Senior w/o promo path     →  keep Intel, reject QC
  Amazon clears HM + ≥ ₹80L    →  Amazon (renege Intel if accepted)
  Cerebras                     →  cash sign-on as leverage only

  Default if AMD + QC + Amazon all fail →  honor Intel
```
