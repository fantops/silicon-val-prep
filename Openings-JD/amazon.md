# Amazon — SoC Validation Engineer, Lab126 (AZ1 Neural Edge / next-gen ML accelerator)

**Years required:** 4+ yrs pre-Si SV/UVM + 4+ yrs post-Si (combined ≈ 8) ✓ on years; **UVM is a hard gap.**

## Role

The team that built the AZ1 Neural Edge silicon IP (powering latest Echo) is looking for an SoC Emulation/Validation Engineer for next-generation ML accelerator SoCs.

You'll enable pre-silicon and post-silicon validation/verification of next-gen SoCs on emulation, prototyping, and early silicon. Develop and execute test plans, design test environments, build emulation/prototype models, work with architects, RTL designers, SoC and SW teams.

## Activities

- Develop/review subsystem testplans; help create SoC V&V plan.
- Implement tests/scenarios on multiple platforms.
- Develop and deploy **baremetal drivers** to configure SoC subsystems.
- **Pre-Si:** develop test benches, **transactors and monitors** for Zebu/HAPS; build/runtime infra; debug capabilities; automation.
- **Post-Si:** seamless intersect from pre-Si; port testplans to post-Si; functional + performant compliance.
