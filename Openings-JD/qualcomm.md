# Qualcomm — CPU Core Validation Engineer (Oryon — pipeline arch / μarch)

**Years required:** **12+ yrs** ← HARD GAP (you: 8)

## Job Overview

As a CPU Core Validation Engineer you'd be part of the CPU Validation team in the CPU org, working on validation of **CPU core pipeline arch and micro-arch features** (Oryon).

## Responsibilities

- Develop detailed test plan considering IP arch and **μarch features**.
- Work with CPU design and verification teams on bringup and functional validation test plans.
- Develop validation methodology and test contents for **emulators (pre-Si) and Silicon**.
- Work with SoC bringup and SW teams for CPU core feature bringup + end-to-end validation.
- Triage and debug failures on Silicon.
- Develop test contents and testing strategies for CPU validation on silicon.
- Work with CPU verification teams to **reproduce silicon fails on emulators and FPGAs**.
- Work with design team to suggest/architect new debug features for future CPU bringups.

## Minimum Requirements

- BA/BS in CS/EE with **12+ yrs experience** ← you have 8
- 12+ yrs in Silicon Validation and bringup
- **Implementation of assembly, C/C++** embedded firmware
- SW toolchain: assemblers, C compilers, Makefiles, source control

## Preferred Requirements

- Good understanding of **micro-processor architecture**:
  - Cache Coherence
  - Memory ordering and Consistency
  - Prefetching
  - Branch Prediction
  - Renaming
  - Speculative execution
  - Address Translation / Memory Management
- **Random Instruction Sequencing (RIS)** for testing block/unit-level and subsystem/chip-level correctness
- Writing Test plans and **Assembly code**
- Independent on a block/unit
